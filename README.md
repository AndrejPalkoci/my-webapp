# My Web App

A Python web application developed as part of my studies at The Hague University of Applied Sciences (THUAS).

## About
This project is a Flask-based web application connected to a MongoDB database, deployed via Railway. It was built to demonstrate full-stack Python development including backend logic, database integration, and cloud deployment.

## Tech Stack
- Python / Flask
- MongoDB
- Railway (deployment)
- REST API

## Setup
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Set your MongoDB connection string as an environment variable: `MONGODB_URI=your_connection_string`
4. Run the app: `python app.py`
